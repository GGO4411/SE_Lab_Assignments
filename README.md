# Software Engineering Lab Assignments

This repository contains my Software Engineering laboratory work for PES University.

## Labs

- **Lab 6 – Code and Branch Coverage:** Implements and tests the password policy application using separate pytest suites to achieve and verify code coverage and branch coverage.
- **Lab 7 – Fuzz Testing:** Uses Hypothesis with pytest to generate varied inputs, uncover edge cases in the password policy application, and validate the fixes.

Each lab's folder contains its source code, test files, and relevant screenshots or supporting documentation.
